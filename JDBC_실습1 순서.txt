프로젝트 진행순서

 데이터베이스(SQL)

  1. 계정생성(C##KH, KH) 권한설정
  2. SEQUENCE 생성(SEQ_USERNO), NOCACHE
  3. MEMBER TABLE 설계, 제약조건
  4. 데이터 입력 확인

 서버(CONTROLLER, DAO(VO, DTO, DAO)) 
  - 추천순서 VO -> DAO -> CON -> DTO
  1. 패키지생성(com.kh.model.vo, com.kh.model.dao, com.kh.controller, com.kh.view, com.kh.run)

  2. com.kh.run.Run.java 클래스에 main() 생성
  3. com.kh.vo Member 클래스 만들기 (모든멤버정의, 기본생성자, 매인생성자, getter / setter, tostring)
  4. com.kh.model.dao MemberDao.java 클래스 만들기
   (회원정보 입력, 모든회원정보 출력, 아이디조회 회원정보, 아이디 조회 수정, 아이디 조회 삭제)
   1) 회원정보 입력 : int insertMember(Member m)
   2) 모든회원 정보출력 : ArrayList<Member> selectList()
   3) 아이디 회원정보 : Member selectById(String userId) => Member selectById(Member m)
   4) 아이디 회원수정 : int updateById(Member m)
   5) 아이디 회원삭제 : int deleteById(Member m)
  
  5. Controller 클래스를 만든다 (view에서 요청을 하면 (insert, update, delete, select, ...)
   
   1) 회원정보 입력 요청 : void insertMember(userId, userPw, userName, gender, Age, email, address, phone, hobby)
   2) 모든회원 정보 출력 요청 : void selectList()
   3) 아이디 회원정보 출력 요청 : void selectById(userId)
   4) 아이디 회원수정 요청 : void updateById(userId, userPw, userName, address, phone, hobby)
   5) 아이디 회원삭제 요청 : void deleteById(String userId)
 
화면 (VIEW) com.kh.view.MemberView
  
  1) 메뉴에서 처리할 내용 정의 (mainMenu())
    - 회원추가
    - 전체 회원 조회
    - 회원 아이디로 검색
    - 회원 정보수정
    - 회원 탈퇴
    - 회원 이름 검색
    - 프로그램 종료
    >> 메뉴번호
 
  2) 화면별 Controller 요청을 해주는 함수
    - void insertMember()	: 사용자에게 회원정보를 입력을 받고, 컨트롤러에게 정보전달 후 회원가입요청
    - void selectList()	: 컨트롤러에게 회원정보 전체 데이터를 달라고 요청
    - void selectById()	: 사용자에게 회원 아이디를 받아 컨트롤러에게 전달하고 그 회원의 정보 요청
    - void updateMember()	: 사용자가 업데이트 내용을 입력하고 컨트롤러 업데이트 요청
    - void deleteMember()	: 사용자가 삭제할 회원의 아이디를 입력하고 컨트롤러에게 삭제 요청
    - void selectByName()	: 사용자가 이름을 입력하고 컨트롤러에게 입력된 이름의 정보를 요청

  3) 컨트롤러에서 리턴받은 값을 출력해주는 화면설계
    - 성공메세지를 출력하는 화면 : void displaySuccess(String message){ sysout };
